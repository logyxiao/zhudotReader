# 局域网同步验证

在 macOS 上运行：

```sh
swiftc -parse-as-library ZhudotReader/Services/LANReadingSync.swift tests/LANReadingSyncSmoke.swift -o /tmp/zhudot-lan-smoke
/tmp/zhudot-lan-smoke
```

测试使用临时端口，通过真实 HTTP 请求检查页面、鉴权、Unicode 正文、双向进度、旧版本拒绝、范围检查、书籍关闭和服务停止。测试不读取书库。

实机验收：

1. 打开一本书，点击工具栏二维码，开启当前书籍同步。
2. 手机与电脑连接同一 Wi-Fi，用相机扫码，在浏览器打开；如系统询问，允许本地网络访问。
3. 手机应从电脑当前位置开始；两端分别滚动，另一端应在约两秒内跟随。
4. 检查中文、emoji、章节跳转、字号和夜间模式；刷新后应从电脑保存的位置恢复。
5. 关闭共享书籍后，手机提示同步结束。关闭同步后，旧链接不再能请求正文；重新开启需重新扫码。
6. 若存在多个网络地址，在二维码面板切换至与手机相同网段的地址。访客 Wi-Fi、客户端隔离或防火墙禁止入站时可能无法连接。

当前范围：单本书的浏览器阅读与阅读位置双向同步。电脑需保持运行；不包含离线书库复制。正文按纯文本显示。两个设备同时操作时，服务器最后接收的位置生效。
